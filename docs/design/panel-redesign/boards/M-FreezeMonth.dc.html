A frozen month can never be edited, removed or replaced — the database refuses all three, including for us. There is no undo and no credit note in this release, so a month frozen by mistake stays as it is until a correction is designed for it.

The figures above are a live count taken when this page was drawn. Freezing counts again at that moment, from the same definition, so a person hired or deactivated in between changes what is stored. Nothing you can type here sets the amount.

What is frozen is the NUMBER of people, not which people. Nothing stored here can reconstruct the list later, and after somebody is anonymised the question has no answer at all — so this figure is an invoice, never an itemised one.
