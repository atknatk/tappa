What this page does not see A plaque page that was opened and never used is not recorded anywhere, so the number of opened-but-unused pages is not on this screen. What IS on it is the counter gap above: the plaque's own chip counts every read, so collected pages leave a jump behind whether or not they are ever used. Which device a person signed in from is not recorded either — only a coarse browser family, which every phone of the same make shares. So "several people activated from one device" cannot be told from "several people use the same model of phone", and this page does not guess at it. The list of people who tap together compares each tap with the ONE before it at that venue. Where three people arrive in a burst, the first and the third are not paired with each other — the two neighbouring pairs are listed instead, so the group is visible but that one combination is not.
